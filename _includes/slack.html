{%- comment -%} Render a link to a Slack channel using the metadata in site.channels (in _config.yml). Usage: {% include slack.html channel="help-macos" %} Optional parameters: text="..." Override the visible link text (default is #channel-name in code font). If the channel is not present in site.channels, the name is still rendered (in code font, but not linked), along with an HTML comment so the problem shows up when grepping the generated site for "UNKNOWN SLACK CHANNEL". {%- endcomment -%} {%- assign slack_channel = site.channels[include.channel] -%} {%- if include.text -%} {%- assign slack_text = include.text -%} {%- else -%} {%- capture slack_text -%}#{{ include.channel }}{%- endcapture -%} {%- endif -%} {%- if slack_channel -%} {{ slack_text }} {%- else -%} {{ slack_text }} {%- endif -%}
